AAU AI Setup Guide

Fra tom computer til fuldt udviklingsmiljø. Følg trinene i rækkefølge — det tager ca. 30-45 minutter.

1. VSCode 2. Miniconda 3. Git 4. Miljø 5. Extensions 6. Test

1 Installer VSCode

VSCode (Visual Studio Code) er den editor vi bruger til at skrive kode.

  1. Gå til code.visualstudio.com
  2. Download og kør installeren for dit system
💡 Windows: Sæt flueben i "Add to PATH" og "Add 'Open with Code' action" under installationen. Det gør livet nemmere senere.

2 Installer Miniconda

Miniconda styrer dine Python-versioner og pakker. Vi bruger Miniconda frem for fuld Anaconda, fordi den er meget mindre og hurtigere.

  1. Gå til Miniconda download og hent Windows-installeren (64-bit)
  2. Kør installeren. Vælg "Just Me" når den spørger
  3. Efter installation: åbn "Anaconda Prompt" fra Start-menuen (ikke almindelig cmd)
⚠️ På Windows skal du bruge Anaconda Prompt til conda-kommandoer, medmindre du har initialiseret conda i PowerShell.
  1. Gå til Miniconda download
  2. Vælg Apple Silicon (M1/M2/M3/M4) eller Intel afhængigt af din Mac
  3. Kør .pkg installeren, eller brug terminalen
💡 Er du i tvivl om chip: klik Apple-menu → "Om denne Mac". Står der "Apple M..." er det Apple Silicon.

Bekræft at det virker ved at åbne en ny terminal / Anaconda Prompt og skrive:

conda --version
✅ Du skal se noget i stil med conda 24.x.x

3 Installer Git

Git bruges til versionsstyring og til at hente kode fra GitHub.

  1. Hent Git fra git-scm.com
  2. Kør installeren — standardvalgene er fine, klik bare "Next" igennem

På Mac er den nemmeste vej via terminalen:

xcode-select --install

Det installerer Git sammen med Apples udviklerværktøjer.

Sæt dit navn og email op (brug din rigtige — det bruges i dine commits):

git config --global user.name "Dit Navn"
git config --global user.email "din@email.dk"
✅ Test med git --version

4 Opret dit conda-miljø

Nu laver vi et isoleret Python-miljø med alle de pakker I skal bruge: numpy, pandas, matplotlib, scikit-learn, jupyter og seaborn.

Hent setup-filerne

Klon dette repo (skift DIT-BRUGERNAVN ud med det rigtige):

git clone https://github.com/DIT-BRUGERNAVN/aau-setup.git
cd aau-setup

Opret miljøet

Denne ene kommando installerer alt fra environment.yml:

conda env create -f environment.yml

Det tager et par minutter. Aktivér så miljøet:

conda activate aau-ai
✅ Din terminal-prompt skulle nu starte med (aau-ai)
💡 Hver gang du åbner en ny terminal for at arbejde på et AI-projekt, kør conda activate aau-ai først.

5 VSCode extensions

Åbn VSCode, klik på Extensions-ikonet i venstre side (eller Ctrl+Shift+X), og installer:

  • Python (af Microsoft) — kernefunktionalitet
  • Pylance — smart kodehjælp og fejlfinding
  • Jupyter — til at køre notebooks direkte i VSCode
  • GitLens — gør Git meget nemmere at bruge
💡 Efter installation: tryk Ctrl+Shift+P (Mac: Cmd+Shift+P), skriv "Python: Select Interpreter" og vælg aau-ai. Så bruger VSCode det rigtige miljø.

6 Test at alt virker

Lad os tjekke at hele opsætningen fungerer. Opret en fil test.py og indsæt:

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import sklearn

print("NumPy:", np.__version__)
print("Pandas:", pd.__version__)
print("scikit-learn:", sklearn.__version__)
print("Alt virker! 🎉")

Kør den med (husk conda activate aau-ai først):

python test.py
✅ Ser du versionsnumre og "Alt virker!" er du helt klar. Velkommen til! 🚀

Hjælp & fejlfinding

"conda: command not found" — Luk terminalen og åbn en ny. På Windows: brug Anaconda Prompt.

VSCode finder ikke aau-ai — Genstart VSCode, kør så "Python: Select Interpreter" igen.

git clone fejler — Tjek at du har kopieret URL'en korrekt og at Git er installeret (git --version).
