AAU AI Setup Guide

Fra tom computer til fuldt udviklingsmiljø. Følg trinene i rækkefølge — det tager ca. 30-45 minutter.

1. VSCode 2. Miniconda 3. Git 4. Miljø 5. Extensions 6. Test 7. Første opgave

1 Installer VSCode

VSCode (Visual Studio Code) er den editor vi bruger til at skrive kode.

  1. 👉 Download VSCode her — vælg din platform (Windows / Mac)
  2. Kør installeren
✅ Windows — HUSK disse flueben under installationen:
  • "Add to PATH" — så du kan starte VSCode med kommandoen code
  • "Add 'Open with Code' action to file/directory context menu" — så du kan højreklikke en mappe og åbne den direkte i VSCode
💡 Mac: Træk VSCode til Applications-mappen efter download. For at bruge code-kommandoen: åbn VSCode, tryk Cmd+Shift+P, skriv "Shell Command: Install 'code' command in PATH" og tryk Enter.

2 Installer Miniconda

Miniconda styrer dine Python-versioner og pakker. Vi bruger Miniconda frem for fuld Anaconda, fordi den er meget mindre og hurtigere.

🚫 Installer IKKE Python separat! Python følger med Miniconda. Hvis du både henter Python fra python.org og Miniconda, kommer de to til at slås om PATH — det er den klassiske kilde til "python virker ikke"-problemer. Én Python = ét mindre problem.
🚫 Hent ALDRIG Python eller Miniconda fra Microsoft Store. Store-versionen roder med PATH og conda på måder der er næsten umulige at debugge. Brug kun de officielle downloads herunder.

Direkte download (springer over reklame-siden):

👉 Download Miniconda til Windows (64-bit)

Eller find den manuelt på anaconda.com/download under "Miniconda Installers".

  1. Kør installeren
  2. Vælg "Just Me (recommended)" når den spørger
  3. På skærmen "Advanced Installation Options", sæt flueben i:
    • ✅ "Add Miniconda3 to my PATH environment variable" — dette er KRITISK. Den advarer at det ikke anbefales, men gør det alligevel, ellers kan du ikke bruge conda i almindelig terminal/VSCode
    • ✅ "Register Miniconda3 as my default Python"
  4. Klik Install og lad den køre færdig
💡 Efter installation: luk ALLE åbne terminaler og VSCode, og åbn en ny. PATH-ændringer virker først i nye vinduer.

Vælg den rigtige til din chip:

👉 Download til Apple Silicon (M1/M2/M3/M4)

👉 Download til Intel Mac

💡 Er du i tvivl om chip: klik Apple-menu → "Om denne Mac". Står der "Apple M..." er det Apple Silicon. Står der "Intel" er det den anden.
  1. Kør .pkg-installeren og følg trinene
  2. Efter installation: luk terminalen og åbn en ny, så conda bliver aktiveret

Bekræft at det virker ved at åbne en ny terminal (Windows: brug Anaconda Prompt fra Start-menuen hvis conda ikke virker i almindelig terminal) og skrive:

conda --version
✅ Du skal se noget i stil med conda 24.x.x
⚠️ Får du conda: command not found? Se fejlfindingssektionen nederst — det er næsten altid PATH eller et gammelt terminal-vindue.

3 Installer Git

Git bruges til versionsstyring og til at hente kode fra GitHub.

  1. Hent Git fra git-scm.com
  2. Kør installeren — standardvalgene er fine, klik bare "Next" igennem

På Mac er den nemmeste vej via terminalen:

xcode-select --install

Det installerer Git sammen med Apples udviklerværktøjer.

Sæt dit navn og email op (brug din rigtige — det bruges i dine commits):

git config --global user.name "Dit Navn"
git config --global user.email "din@email.dk"
✅ Test med git --version

4 Opret dit conda-miljø

Nu laver vi et isoleret Python-miljø med alle de pakker I skal bruge: numpy, pandas, matplotlib, scikit-learn, jupyter og seaborn.

Hent setup-filerne

Klon dette repo:

git clone https://github.com/Steffen1508/aau-setup.git
cd aau-setup

Opret miljøet

Denne ene kommando installerer alt fra environment.yml:

conda env create -f environment.yml

Det tager et par minutter. Aktivér så miljøet:

conda activate aau-ai
✅ Din terminal-prompt skulle nu starte med (aau-ai)
💡 Hver gang du åbner en ny terminal for at arbejde på et AI-projekt, kør conda activate aau-ai først.

5 VSCode extensions

Åbn VSCode, klik på Extensions-ikonet i venstre side (eller Ctrl+Shift+X), og installer:

  • Python (af Microsoft) — kernefunktionalitet
  • Pylance — smart kodehjælp og fejlfinding
  • Jupyter — til at køre notebooks direkte i VSCode
  • GitLens — gør Git meget nemmere at bruge
💡 Efter installation: tryk Ctrl+Shift+P (Mac: Cmd+Shift+P), skriv "Python: Select Interpreter" og vælg aau-ai. Så bruger VSCode det rigtige miljø.

6 Test at alt virker

Lad os tjekke at hele opsætningen fungerer. Opret en fil test.py og indsæt:

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import sklearn

print("NumPy:", np.__version__)
print("Pandas:", pd.__version__)
print("scikit-learn:", sklearn.__version__)
print("Alt virker! 🎉")

Kør den med (husk conda activate aau-ai først):

python test.py
✅ Ser du versionsnumre og "Alt virker!" er du helt klar. Videre til din første opgave! 🚀

7 Din første opgave

Nu hvor miljøet kører, skal du prøve hele arbejdsgangen af: oprette et GitHub-repo, arbejde i VSCode, og committe og pushe din kode. Til sidst tegner du et hus med pygame. Følg punkterne i rækkefølge.

7.1 — Opret en GitHub-profil

  1. Gå til github.com/signup og opret en konto, hvis du ikke allerede har en.
  2. Brug gerne den samme email som du satte op i Git i trin 3 — så hænger dine commits sammen med din profil.
💡 Som studerende kan du få gratis ekstra-funktioner via GitHub Student Developer Pack. Ikke nødvendigt for opgaven, men rart at vide.

7.2 — Lav en mappe til dine opgaveløsninger

Denne mappe bliver dit private GitHub-repo, hvor du gemmer alle dine opgaver gennem kurset.

🚫 Læg IKKE mappen i OneDrive, Dropbox eller lignende sky-mapper. De synkroniserer i baggrunden og kommer i karambolage med Git — det giver mærkelige konflikter og ødelagte filer. Læg den et almindeligt sted, fx Documents/aau eller direkte i din hjemmemappe.

Opret mappen og gå ind i den (tilpas navn/sti som du vil):

cd %USERPROFILE%\Documents
mkdir aau-opgaver
cd aau-opgaver
cd ~/Documents
mkdir aau-opgaver
cd aau-opgaver

7.3 — Opret et privat repo på GitHub

  1. På GitHub: klik på + øverst til højre → New repository.
  2. Giv det et navn (fx aau-opgaver), vælg Private, og opret det uden README (den laver vi selv i næste trin).
  3. Kopiér repo'ets URL — du får brug for den om lidt.

7.4 — Opret README.md i VSCode

Åbn mappen i VSCode (code . fra terminalen, eller højreklik mappen → "Open with Code"). Opret en fil ved navn README.md og skriv dit navn i den:

# Dit Navn

AAU AI — opgaveløsninger

7.5 — Commit og push til GitHub

Første gang kobler du din lokale mappe sammen med dit GitHub-repo. Kør i terminalen (stå i mappen):

git init
git add README.md
git commit -m "Tilføj README med mit navn"
git branch -M main
git remote add origin DIN-REPO-URL
git push -u origin main
⚠️ Erstat DIN-REPO-URL med URL'en fra trin 7.3, fx https://github.com/ditbrugernavn/aau-opgaver.git. Bliver du bedt om at logge ind, følg login-vinduet fra GitHub.
✅ Gå ind på din GitHub-side og bekræft at README.md nu ligger der, og at dit navn vises.
💡 Fremover er arbejdsgangen bare: git add . → git commit -m "besked" → git push.

7.6 — Lav en undermappe: Lektion 1

Opret en undermappe i dit repo:

mkdir "Lektion 1"

7.7 — Installér pygame

Sørg for at dit miljø er aktivt (conda activate aau-ai), og installér så:

pip install pygame
✅ Test med python -m pygame.examples.aliens — der skulle gerne åbne et lille spil-vindue.

7.8 — Klon draw-projektet

Klon draw-projektet et sted uden for dit eget repo (fx i din hjemmemappe), så de to repos ikke blandes sammen:

git clone https://github.com/andreasmoegelmose/draw/tree/master

7.9 — Kopiér draw.py ind i Lektion 1

Kopiér draw.py fra din klon over i din Lektion 1-mappe:

copy draw\draw.py "aau-opgaver\Lektion 1\draw.py"
cp draw/draw.py "aau-opgaver/Lektion 1/draw.py"
💡 Du kan også bare trække filen fra én mappe til en anden i VSCode's filpanel — det virker lige så godt.

7.10 — Tegn et hus 🏠

Nu til det sjove. Ret draw.py så du tegner et hus — gør det flot med mange farver. Arbejd i to trin:

  1. Start med kun at bruge flere kald til pygame.draw.line(), så du får styr på hvordan koordinatsystemet virker (0,0 er øverste venstre hjørne).
  2. Kopiér så draw.py til draw_with_shapes.py: 
    copy "aau-opgaver\Lektion 1\draw.py" "aau-opgaver\Lektion 1\draw_with_shapes.py"
    cp "aau-opgaver/Lektion 1/draw.py" "aau-opgaver/Lektion 1/draw_with_shapes.py"
  3. Prøv i draw_with_shapes.py at tegne huset med firkanter og andre former i stedet for løse linjer. Slå funktionerne op her: pygame.draw-dokumentationen (rect, polygon, circle og ellipse er gode at kigge på).
💡 Husk at committe undervejs — fx når linje-versionen virker, og igen når form-versionen er færdig. Så øver du dig i den rigtige arbejdsgang, og du kan altid gå tilbage.

7.11 — Fælles GitHub med din P0-gruppe

Til sidst: lav et fælles repo sammen med din P0-gruppe, og giv alle adgang.

  1. Én i gruppen opretter et nyt repo (som i trin 7.3).
  2. Gå ind i repo'et → Settings → Collaborators → Add people, og tilføj de andres GitHub-brugernavne.
  3. De andre får en invitation (tjek email eller notifikationer på GitHub) og skal acceptere den, før de har adgang.
✅ Alle i gruppen kan klone repo'et og pushe til det. Nu er I klar til at arbejde sammen om koden.

Hjælp & fejlfinding

"conda: command not found" / "conda genkendes ikke"

Dette er langt det mest almindelige problem. Prøv i rækkefølge:

  1. Luk ALLE terminaler og VSCode helt, og åbn et nyt vindue. PATH-ændringer gælder først i nye vinduer — 9 ud af 10 gange er det bare det.
  2. Windows: Åbn "Anaconda Prompt" fra Start-menuen i stedet for almindelig cmd/PowerShell. Der virker conda altid.
  3. Vil du have conda i almindelig PowerShell, kør én gang i Anaconda Prompt: conda init powershell, luk og åbn PowerShell igen.
  4. Virker det stadig ikke? Så blev "Add to PATH"-fluebenet sandsynligvis ikke sat under installationen. Nemmeste fix: afinstaller Miniconda og installer forfra — husk fluebenet denne gang.

"python" åbner Microsoft Store

Det betyder at Windows' Store-genvej blokerer den rigtige Python. Fix: åbn Windows-indstillinger → søg "Administrer aliaser for app-udførelse" (Manage app execution aliases) → slå begge "python.exe" og "python3.exe" FRA. Luk terminalen og prøv igen.

VSCode finder ikke aau-ai-miljøet

Genstart VSCode helt. Tryk så Ctrl+Shift+P (Mac: Cmd+Shift+P) → "Python: Select Interpreter" → vælg den der indeholder aau-ai. Ser du den ikke på listen, så tjek at miljøet blev oprettet med conda env list.

"conda env create" fejler eller hænger

Tjek at du står i den rigtige mappe (cd aau-setup) og at environment.yml ligger der (dir på Windows, ls på Mac). Hvis download hænger, så tjek din internetforbindelse og prøv igen — conda genoptager typisk.

git clone fejler

Tjek at URL'en er kopieret korrekt og at Git er installeret (git --version). Får du en fejl om authentication, så tjek at repo'et er offentligt, eller log ind på GitHub.

git push beder om brugernavn/adgangskode hele tiden

GitHub tillader ikke længere almindeligt kodeord i terminalen. Nemmeste vej er login-vinduet der popper op første gang (Git Credential Manager husker dig bagefter). Virker det ikke, kan du oprette et Personal Access Token og bruge det som adgangskode.

pygame-vinduet åbner ikke / lukker med det samme

Tjek at miljøet er aktivt ((aau-ai) foran i prompten) og at du kørte pip install pygame mens det var aktivt. Sørg også for at din kode har en event-løkke, så vinduet ikke bare lukker igen med det samme.

Stadig i tvivl? Spørg din tutor 🙂
