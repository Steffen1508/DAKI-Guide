# AAU AI Setup Guide 🚀

Velkommen til Design og Udvikling af Kunstig Intelligens! Denne guide får dig fra en tom computer til et fuldt fungerende udviklingsmiljø med **VSCode, Python, Conda, Git** og de vigtigste pakker.

Følg trinene i rækkefølge. Det tager ca. 30-45 minutter.

👉 **[Åbn den pæne guide her](https://DIT-BRUGERNAVN.github.io/aau-setup/)** (når du har slået GitHub Pages til)

---

## Hurtig oversigt

| Trin | Hvad | Tid |
|------|------|-----|
| 1 | Installer VSCode | 5 min |
| 2 | Installer Miniconda | 5 min |
| 3 | Installer Git | 5 min |
| 4 | Opret dit conda-miljø | 10 min |
| 5 | VSCode extensions | 5 min |
| 6 | Test at alt virker | 5 min |

---

## Kom hurtigt i gang (for de utålmodige)

Når Miniconda og Git er installeret:

```bash
# Klon dette repo
git clone https://github.com/DIT-BRUGERNAVN/aau-setup.git
cd aau-setup

# Opret miljøet med alle pakker
conda env create -f environment.yml

# Aktivér det
conda activate aau-ai
```

Se den fulde guide i `docs/` mappen eller på GitHub Pages siden.
